01 — ROBOTICS / HANDS-ON

Popsicle-Stick Robotic Arm

IN PROGRESS — Prototype is still being built and tested.

Project Overview

This project involves building a small robotic arm using popsicle sticks, servo motors, and an Arduino-based control setup. The goal is to create a working arm that can move through different positions and operate a small claw.

Design & Construction

The frame was assembled using popsicle sticks to create the arm structure and moving joints. Servo motors were added to control different sections of the arm.

Testing & Improvements

The prototype is being tested as the motors and mechanical structure are adjusted. Future improvements will focus on smoother movement, better stability, and improving the overall design.

This project is a work in progress. More photos and updates will be added as development continues.
